# Mon cahier manga

150 dessins originaux à colorier, avec le modèle en couleur à côté : héros manga, chibis, duos, dessins animés, mécha et science-fiction, voyage au Japon et mandalas.

**Ouvrir le cahier :** https://farelello2018-debug.github.io/cahier-manga/

## Installer l'appli

- **iPhone et iPad** : ouvre le lien dans Safari, touche le bouton Partager, puis « Sur l'écran d'accueil ».
- **Android** : ouvre le lien dans Chrome, touche le menu ⋮, puis « Installer l'application ».

Une fois installée, l'appli fonctionne sans internet. Les coloriages restent sur l'appareil : pas de compte, pas de publicité, aucune donnée collectée.

## Mettre à jour

1. Remplacer `index.html` et `art.js`.
2. Changer le numéro de `VERSION` dans `sw.js`, pour que les téléphones récupèrent la nouvelle version.
